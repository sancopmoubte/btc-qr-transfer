# BTC 离线二维码转账

这是基于 [`btc-quantum-miner`](https://github.com/sancopmoubte/btc-quantum-miner) 的独立静态网页版本。原网页不做任何修改；本项目保留原有的身份、余额、ECDSA 签名、离线转账、挖矿与提现功能，核心改动是：

- 发起转账后生成二维码，不再要求复制一长串 Base64 凭证。
- 接收方可以上传二维码图片，或在 HTTPS 页面使用摄像头扫码。
- 支持下载和系统分享二维码图片。
- 保留“手动粘贴旧版凭证”作为兼容备用入口。
- 凭证格式使用 `BTCQ1.` 前缀，并兼容原网页的无前缀 Base64 凭证。

## 在线使用

部署到 GitHub Pages 后，打开网页：

1. 在“身份”中生成身份。
2. 在“挖矿/提现”中生成一些演示余额。
3. 将接收方的公钥粘贴到“发起转账”，输入金额并生成二维码。
4. 把二维码图片发送给接收方。
5. 接收方在“扫码接收”中上传图片或打开摄像头，验证后入账。

## 说明

这是浏览器本地运行的离线代币演示系统，不会广播真实 Bitcoin 主网交易，也不会替代真实钱包。余额、私钥和已使用 nonce 保存在当前浏览器的 `localStorage` 中。二维码只承载经过发起方 ECDSA 签名的离线转账凭证。

## 部署

本项目只有 `index.html`，不需要构建工具。将仓库启用 GitHub Pages（Source 选择 `Deploy from a branch`，分支选择 `main` / `/root`）即可。

二维码生成依赖 qrcodejs，二维码识别依赖 jsQR，均通过 CDN 加载；若 CDN 不可用，页面仍可打开，但生成/识别二维码功能需要网络访问对应脚本。
